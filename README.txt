3D-МОДЕЛЬ СТРУКТУРЫ ЛИЧНОСТИ СПОРТСМЕНА

Запуск:
1. Откройте index.html в Chrome/Edge/Firefox.
2. Для загрузки Three.js нужен интернет, потому что библиотека подключена через CDN.
3. ЛКМ — вращение, колесо — масштаб, наведение/клик по качествам — интерактив.

Что исправлено:
- квадратный glow заменён на радиальную CanvasTexture;
- добавлен мягкий cinematic light/beam;
- сохранён тёмный HUD-интерфейс, карточки, диаграмма и интерактивные показатели;
- центральная фигура остаётся процедурной Three.js-моделью без внешних 3D-файлов.

Для фотореалистичного человека уровня рендера нужен отдельный GLB/GLTF-персонаж. Его можно подключить через GLTFLoader, не меняя интерфейс.
